# OriginType

**Train the hand. Teach the system.**

OriginType is an open-source AI-powered handwriting tutor that teaches print writing, cursive, signature design, and advanced typography through adaptive lessons, printable worksheets, and AI-driven feedback from handwriting uploads or stylus input.

It bridges the gap between **learning to write by hand** and **designing functional typefaces**.

---

## Features

### ✏️ Core Handwriting Learning System
- Adaptive handwriting lessons (print → cursive progression)
- Traceable and printable worksheets generated dynamically
- Letter-by-letter stroke guidance and sequencing
- Baseline, slant, spacing, and alignment training
- Difficulty scaling based on student performance

### 🖊️ Multi-Tool Writing Support
- Pencil-based foundational training (correction-friendly learning)
- Pen-based confidence writing (permanent stroke discipline)
- Stylus/tablet handwriting capture and evaluation
- Cross-device consistency tracking

### 📸 AI Handwriting Analysis
- Upload handwritten pages via image capture
- Computer vision preprocessing for alignment and cleanup
- Stroke consistency detection
- Spacing and kerning behavior analysis (early typographic signals)
- Slant drift and baseline stability detection
- Legibility scoring with improvement tracking

### 🧠 Adaptive AI Tutor Engine
- Personalized lesson generation based on performance history
- Error-targeted practice sheets (weakness-focused training)
- Progressive skill unlocking system
- Real-time feedback suggestions after uploads
- Student progression modeling over time

### ✍️ Signature Development System
- Guided signature creation workflow
- Balance between individuality and readability
- Iterative refinement stages:
  - Structured name writing
  - Compression and stylization
  - Motion simplification
  - Final signature stabilization
- Repeatability validation for consistency

### 🔤 Advanced Typography Track
- Transition from handwriting to font design
- Glyph construction from student letterforms
- Bézier curve reconstruction from stroke data
- Basic font consistency enforcement
- Spacing and kerning assistance system
- Export of personal fonts (OTF / TTF)
- Early-stage typeface design education

### 🧾 Printable Learning Engine
- Auto-generated worksheets for any skill level
- Name-based personalized practice sheets
- Cursive flow drills and repetition pages
- Slant and grid-guided practice pages
- Offline learning support via print-ready PDFs

### 🔐 Privacy & Deployment
- Self-hostable architecture
- Encrypted handwriting data storage
- Local-first deployment option for schools
- No behavioral tracking or data monetization
- Education-safe design for minors
